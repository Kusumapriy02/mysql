Date and Time functions
================================
curdate():returns the current date;
SYNTAX: select CURDATE() AS CURRENT__DATE;
curtime():returns the current time
SYNTAX:SELECT CURTIME() AS CURRENT__TIME;
now() returns the current date and time
SYNTAX:SELECT NOW() AS CURRENT_DATE_TIME;
date(): extract date part
SYNTAX:SELECT DATE(NOW()) AS EXTRACTED_DATE;
time(): extract time part
SYNTAX: SELECT TIME(NOW()) AS EXTRACTED_TIME
year(): extract year
SYNTAX:SELECT YEAR(NOW()) AS YEAR_PART;
month(): extract month part
SYNTAX:SELECT MONTH(NOW()) AS MONTH_PART;
day()/day of month() extract day of month:
SYNTAX: SELECT DAY(NOW()) AS DAY_PART;
week():extract week() number
SYNTAX:SELECT WEEK(NOW()) AS WEEK_NUMBER;
dayofweek():extract day of the week
SYNTAX:SELECT DAYOFWEEK(NOW()) AS DAY_OF_WEEK;
date_add() add a date 
 SYNTAX:SELECT DATE_ADD(NOW(),INTERVAL 20 DAY) AS NEW_DATE;
date_sub():
SYNTAX: SELECT DATE_SUB(NOW(),INTERVAL 20 DAY) AS NEW_DATE;
